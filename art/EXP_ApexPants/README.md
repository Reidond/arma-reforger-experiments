# MCDU APEX pants, Multicam — art source

Reference product: [Брюки MCDU APEX, цвет Multicam](https://voinmarket.com/catalog/product/bryuki_mcdu_apex_tsvet_multicam/)
(product photos go in `reference/`, gitignored — not ours to redistribute).

Everything here is generated by scripts, so the model can be rebuilt or tweaked
by editing numbers instead of hand-sculpting.

| Path | What |
| --- | --- |
| `EXP_ApexPants.blend` | Working file, scene `ApexPants`: Reforger template body + skeleton (from `SampleMod_NewCharacter/.../Character_Weights_Template.blend`), `Pants_base` (rest mesh), `Pants_LOD0` (displaced preview), `Pants_MCDU_APEX_LOD0..3` (skinned export meshes), item model, studio lights/camera |
| `scripts/` | The pipeline (below) |
| `textures/source/camo_print_{a,b}.png` | Multicam-style print swatches generated with Codex image generation (1254 px ≈ 62 cm of fabric) |
| `textures/preview/` | PNG maps for the Blender preview material (gitignored, regenerated) |
| `build/` | Intermediate mesh data, vertex displacement, AO bake (gitignored) |
| `renders/` | Cycles renders for review |

## Pipeline

Geometry (Blender, `iterate_geometry.py` runs 1–5):

1. `build_base.py` — trouser shell cut from the template body, loosened to a regular fit
   (`apex_common.LEG_ELLIPSE`), body topology kept and subdivided twice (~68k tris), dents
   removed, hem/waistband turn-ups, sewing-pattern UV seams.
2. `build_parts.py` — real geometry from `apex_parts.py`: bellows cargo/back pockets, solid
   flaps, welts, waistband, 9 belt loops (with a belt gap), zips + pulls, knee straps, cuffs.
   `Pants_full` = shell + parts, one UV atlas, per-vertex `part_id` / `part_fabric`.
3. `export_mesh_data.py` → `build/pants_base.npz`.
4. `setup_preview.py` — `Pants_LOD0` with seam/fold displacement, preview material.
5. `export_game.py` — skinning, LOD1–3, item model, FBX into the mod.

Textures (`uv run gen_textures.py --res 4096 --photos all`):

- Panel layout (olive vs camo) from `apex_panels.py`, read off all reference photos.
- Camo comes from the product photos projected through the mesh posed like each photo
  (`photo_project.py`, views 15/8/13 + mirrored copies; `compare.py` writes the posed meshes),
  photo shading split into relief (`photo_intrinsics.py`); elsewhere the Codex print
  `camo_print_ref_*.png`. Ripstop tile `fabric_detail.png` from a macro photo.
- `bake_ao.py` adds geometric AO.

Checking against the photos: `compare.py` (photo | render at the same angle and pose),
`align_compare.py` (same garment height + guide lines), `photo_lookup.py` / `unwrap_views.py` /
`surface_chart.py` (surface coordinates drawn on the photos / photos unwrapped onto the leg
chart). The reference photos live in `reference/` (gitignored), so texture regeneration needs
them locally.

## Numbers

- LOD0 86.9k tris (shell 68k + parts 19k), LOD1 43.4k, LOD2 21.7k, LOD3 10.4k; 20 bones, max 4 influences.
- Textures 4096², 0.38 mm per texel, 54% UV fill. Ripstop grid 5 mm (measured against the belt).
- Fit: made for the (muscular) Reforger template body. Measured on `Pants_base`: hip
  circumference ≈ 1.09 m (≈ XL on the product size chart), outseam ≈ 0.95 m with the hem
  at the ankle.
